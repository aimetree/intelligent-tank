## 4. 对《样品验证方案》（T-04）的提示

1. **商业一侧的数据从哪里来**　数据表只给厚度、面电阻、溶胀、力学性能这一类〔T3-08〕〔T3-09〕。钒渗透率和电池数据要从同条件比较的论文〔T3-07〕〔T3-24〕和把商业膜当基准的论文里取，并标明不是厂商数据。
2. **跨论文怎么比**　可以沿用 2021 年综述的做法：先看“与同一篇论文里的基准膜之比”，再看绝对值〔T3-03〕。这可以写成“条件化比较”的一条规则。
3. **价格**　公开价格很少。可用的有上市申报材料里的平均售价〔T3-15〕和综述里引用的区间〔T3-05〕，都要标明来源类型（企业披露、第三方分析）。行业资讯网站转述的数字，尽量回到申报稿原文。
4. **文献数量**　定检索式时先用 OpenAlex 数一遍。这次没有数：访问接口的网址需要成员在对话里批准。
5. **来源登记**　以上每个来源都按 D-56 登记许可情况和处理方式。标准全文〔T3-11〕要购买，先只登记题录。
6. **已有的数据库**　PNNL 的数据库〔T3-28〕要申请、没有许可声明，用不用到时再定。

**J-61　“不做判断”划到哪一层**

背景：这会改动之前定的一处，交付的三样内容里有一样是“针对问题的判断”（D-28）。要做的事可以分成三层。

| 层 | 做什么 | 例子 |
|---|---|---|
| 第一层　整理 | 核对来源和测试条件，按规则把能比的分到一组，标明每条数据的类型和核验状态 | 证据表、可比组 |
| 第二层　描述 | 把数据说了什么写出来，只陈述，不评价 | 某一组里能量效率的范围；有几种膜高于基准膜；哪项指标多数论文没测；哪些数据互相矛盾 |
| 第三层　判断 | 评价和建议 | 哪条路线更有前途；离商业化还差什么；值不值得投入 |

| 选项 | 内容 |
|---|---|
| 做到第二层（Claude 的建议） | 整理加描述。耐久性和放大的信息（循环次数、运行时间、膜面积、是否做到电堆）照实列出，不评级；不写评价和建议。样品含：题目卡、核验证据表、对标视图（含“与同一篇论文里的基准膜之比”）、数据概览、耐久与放大、企业与产品及关联、覆盖与缺口、变化记录。“完整”按写明的检索范围来算 |
| 只做第一层 | 只给整理好的数据表，不写归纳文字。最中立，但读者要自己从表里找规律 |
| 三层都做，判断单列 | 保留原设计：判断单独成一节，标明是我们的看法。与“暂时不做判断”不一致 |

Claude 的提醒：去掉判断以后，我们相对顶级 AI 多出来的就全在“更全、更准、条件对得齐、出处找得到”上，对照测试（D-25、D-51）检验的正是这一点。
