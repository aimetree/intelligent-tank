## 2. 几点观察

1. 自己建模、又写明了膜价和占比的只有 C1，它是 2016 年的，早于样品的 2021 年时间窗（D-59）。C2 写了占比和系统规模，没写依据和价格年份。
2. 37% 这个数出现了两次：C2，和 C3 转述的 C4（250 kW 电堆、Nafion）。C2 没有标出处，参考文献里也没有 C4，所以看不出两者是不是同一来源；规模也不一样（C2 是 1 MW/4 MWh 的系统）。报告里两条分开列，各写各的口径，并注明数值相同、关系不明。
3. 各篇的分母不一样：有的是电堆，有的是系统；系统里储能的小时数也不一样（C3 转述的美国能源部分析里，系统大小不同，比例就从 44% 变成 27%）。照方案的规则，这些只按口径并列，不进“直接可比”（方案 10.1 第 16 条）。
4. 膜价的假设差得很远：C1 每平方米 250 欧元，C5 是 200 欧元。占比高低主要跟着这个假设走。
