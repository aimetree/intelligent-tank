## 2. 几点观察

1. 直接是“技术经济性分析”、又直接写了膜占比的，读到的只有 C1。C1 是 2016 年的，早于样品的 2021 年时间窗（D-59）。
2. 37% 这个数出现了三次：C2、C3 转述的 C4。如果 C2 引的就是 C4，那就是同一个来源，不能算两条独立的说法。要读了 C2 的原文才知道。
3. 各篇的分母不一样：有的是电堆，有的是系统；系统里储能的小时数也不一样（C3 转述的美国能源部分析里，系统大小不同，比例就从 44% 变成 27%）。照方案的规则，这些只按口径并列，不进“直接可比”（方案 10.1 第 16 条）。
4. 膜价的假设差得很远：C1 每平方米 250 欧元，C5 是 200 欧元。占比高低主要跟着这个假设走。

不是决定，供 Kai 点选时参考。

- **建议收 C1、C2、C3 三篇。** C1 是自己建模、写明了膜价和占比；C2 是中文来源，单列了电堆和系统两个口径；C3 是综述，记作第三方分析（D-59、D-70），用来把各种说法和它们的原始出处列全。

- C5、C6、C7 不收：C5 没有给占比；C6 是引用；C7 没有核到。

收进来以后的记法，Claude 的看法同《待编入的判断》第 5 节：证据类型记“模型与模拟结果”，C3 记“第三方分析”；写明系统规模、膜的型号和单价假设；只给单价、不给占比的，单价照原文记成一条事实，不由我们算成占比（D-60）。
