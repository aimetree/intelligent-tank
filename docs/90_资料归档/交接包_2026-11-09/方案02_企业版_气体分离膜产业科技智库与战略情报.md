# 01｜服务定位与核心价值

## 1.1 服务定位

面向某膜技术企业在气体分离膜材料、膜组件、工业装备、工程技术及产品商业化领域的专业信息与研究需求，建立覆盖科研、技术、竞争、产品、工程、政策、市场与战略的产业科技智库。其目标不仅是掌握行业新闻，更是将全球分散的科研成果、企业产品、技术指标、工程案例和产业信息，转化为可以持续使用的专业知识及决策依据。

## 1.2 四项核心价值

| 价值 | 服务内容 | 对某膜技术企业的意义 |
|---|---|---|
| 技术前瞻 | 全球科研成果、技术路线和创新生态 | 识别值得关注的研发方向、技术变化和科研团队 |
| 竞争认知 | 竞争企业、膜组件、工程系统、替代技术 | 理解产品竞争力与工程应用条件 |
| 产业洞察 | 政策、标准、市场需求、工程项目和产业链 | 将研发成果与外部需求及商业环境联系 |
| 研究决策 | 技术比较、技术经济性和多领域综合分析 | 形成专业、可核查的研发和商业决策参考 |

## 1.3 服务对象与业务职能

| 对象 | 典型需求 | 服务内容 |
|---|---|---|
| 管理与战略 | 竞争格局、产业趋势与技术路线 | 竞争研究、市场机会和战略分析 |
| 材料研发 | 新材料、科研成果、性能瓶颈 | 科研雷达、技术对标、专利研究 |
| 制膜与制造 | 制备方法、设备、制造技术 | 工艺、制造及产业资源研究 |
| 组件与工程 | 组件规格、工艺流程、工程性能 | 组件、系统技术与工程案例 |
| 数字孪生与算法 | 模型方法、科研团队、工业AI | 数字技术情报、科研与软件对标 |
| 产品与市场 | 竞品、客户需求、应用场景及政策 | 产品图谱、市场与产业项目研究 |

## 1.4 研究工作的基本原则

- 以技术深度和实际应用相关性为优先，而非单纯追求资料数量。

- 明确区分科研材料性能、商业组件性能和工艺系统性能。

- 根据特定分离对象与应用场景判断竞争关系，不机械给企业排名。

- 重要事实保留来源、日期、测试条件及可比性说明。

- 通过跨模块研究形成连续知识，不把每篇论文和每条新闻变成孤立报告。

- 数字孪生与工业AI研究属于A业务的技术情报，具体工程开发另行界定。

# 02｜产业技术全景与总体架构

## 2.1 从材料到工业应用的六层技术链

| 层级 | 主要对象 | 研究重点 |
|---|---|---|
| L1 先进膜材料 | 聚合物膜、复合膜、混合基质膜、无机膜 | 材料结构、分离机理、制备与稳定性 |
| L2 制造与组件 | 中空纤维、卷式等组件及制膜工艺 | 膜层、面积、组件结构及可靠性 |
| L3 工艺与装备 | 多级分离、压缩、预处理及辅助系统 | 工况、流程、系统设计及设备性能 |
| L4 数字工程 | 科学模型、工艺仿真、数字孪生、工业AI | 建模、校准、预测和技术评价 |
| L5 工业应用 | 生物天然气、工业CO₂、氢气及其他气体 | 目标用户、产品要求及经济性 |
| L6 产业生态 | 企业、科研、标准、专利、项目及合作 | 技术竞争与产业发展 |

> **核心比较原则** 实验室材料选择性不等于商业组件的分离性能；某工艺公开的回收率也不能直接代表膜材料优劣。技术研究必须保留分离对象、工况与系统边界。

## 2.2 八大研究模块总览

| 模块 | 研究领域 | 面向某膜技术企业的价值 |
|---|---|---|
| M01 | 科研前沿与技术创新 | 研发技术判断与科研团队研究 |
| M02 | 竞争企业与竞品分析 | 产品竞争、技术路线与商业布局 |
| M03 | 膜组件、工艺与工程系统 | 工程技术与实际应用对标 |
| M04 | 数字孪生与工业AI | 模型、算法、软件及工业技术情报 |
| M05 | 政策法规与标准 | 行业规范、政策及市场准入 |
| M06 | 下游市场与产业项目 | 客户、应用及商业需求 |
| M07 | 专利与产业合作生态 | 知识产权、供应链及合作资源 |
| M08 | 技术经济性与综合战略 | 跨模块分析和决策参考 |

## 2.3 研究体系与成果的关系

| 研究输入 | 专业研究 | 成果输出 |
|---|---|---|
| 论文、企业公告、专利、标准、产品数据、工程案例 | 八大模块交叉分析；条件化比较；来源与证据评价 | 技术雷达、竞争图谱、科研观察、对标矩阵、战略研究 |

模块定义可以研究哪些问题；主题定义当前关注哪些技术和市场；服务产品定义某膜技术企业获得的资料、数据库和专业研究。以同一知识体系支持多类输出，避免不同部门重复整理相同的科研、企业和产品数据。

# 03｜八大专业研究模块

## M01｜全球科研前沿与技术创新

建立先进气体分离膜材料、制备工艺、分离机理和科研团队的全球技术认知。

| 研究方向 | 具体内容 |
|---|---|
| 先进材料 | 聚合物、混合基质、复合与无机膜；材料结构、制备和分离机制 |
| 性能与瓶颈 | 渗透性、选择性、稳定性、抗塑化、老化、杂质与污染耐受 |
| 制造工艺 | 成膜、纺丝、涂层、复合结构及工艺放大研究 |
| 科研方法 | 材料表征、传质研究、计算模拟、机器学习及自动化实验 |
| 研究生态 | 高校、科研机构、重点团队、代表成果与研究方向 |
| 技术转化 | 实验室验证、组件测试、中试、工业应用及其证据 |

### 典型研究问题

- 哪些材料或技术正在出现有意义的突破？

- 论文性能能否在相似测试条件下比较？

- 哪些技术瓶颈仍限制组件化和工业应用？

- 哪些科研团队值得长期追踪？

### 专业成果与跨模块关系

> **主要成果** 全球膜技术雷达；科研团队图谱；技术路线对标；新兴技术研究。

关联研究：与M02比较科研与商业产品，与M07关联专利和知识产权，与M03评价工程适用性。

## M02｜全球竞争企业与竞品分析

建立商业膜材料、组件和分离技术企业的持续竞争情报体系。

| 研究方向 | 具体内容 |
|---|---|
| 竞争企业 | 全球制造商、专业膜组件供应商、系统企业与新兴技术公司 |
| 产品组合 | 产品系列、材料、组件形式、目标分离气体及适用市场 |
| 产品性能 | 公开参数、测试条件、适用工况、可靠性与稳定性 |
| 技术布局 | 研发方向、新产品、公开专利及制造技术变化 |
| 工程能力 | 模拟、选型、设计、系统集成、现场支持及维护 |
| 市场布局 | 客户类型、区域市场、合作伙伴及商业技术服务 |

### 典型研究问题

- 哪些企业与某一分离应用直接竞争？

- 产品数据是否同层级、同工况可比？

- 成熟企业如何提供从材料到工程的完整技术服务？

- 哪些竞争者正在扩展数字化服务？

### 专业成果与跨模块关系

> **主要成果** 全球竞争企业图谱；产品技术数据库；竞品技术矩阵；竞争策略专题。

关联研究：与M03共同分析组件和工程方案，与M06关联客户和市场，与M07关联技术布局。

## M03｜膜组件、工艺与工程系统情报

将材料性能与工业组件、流程和装备联系起来，研究工程技术竞争。

| 研究方向 | 具体内容 |
|---|---|
| 组件设计 | 中空纤维、卷式等结构；有效面积、流动方式、壳体和密封 |
| 分离流程 | 单级、多级、回流以及膜与其他工艺的组合 |
| 辅助设备 | 压缩、真空、预处理、干燥、污染物控制及监测 |
| 工程指标 | 纯度、回收率、处理量、能耗、可靠性和维护 |
| 企业和系统 | 设备制造商、系统集成商、工艺技术供应商 |
| 应用案例 | 公开示范、商业装置及工程运行资料 |

### 典型研究问题

- 不同系统配置怎样影响分离性能和能耗？

- 材料优势转化为工业组件面临哪些条件？

- 哪些工程指标决定客户选择？

- 竞争企业提供哪些模拟和设计支持？

### 专业成果与跨模块关系

> **主要成果** 组件与工程系统图谱；工艺技术研究；工业应用案例库；工程性能对标。

关联研究：连接M01材料技术、M02商业竞品、M04仿真研究及M08经济性。

## M04｜数字孪生、工业AI与先进计算技术

为某膜技术企业已有数字孪生技术合作提供持续科研、模型方法和工业技术情报。

| 研究方向 | 具体内容 |
|---|---|
| 机理建模 | 传质、热力学、动态系统、膜组件与工艺流程模型 |
| 数据驱动 | 机器学习、预测、参数估计及统计建模 |
| 混合模型 | 机理知识与数据驱动技术的结合 |
| 数字孪生 | 模型与实验或真实设备数据的关联及更新 |
| 工业AI | 异常识别、性能预测、优化、Agent和辅助决策 |
| 科研和软件 | 大学团队、代表论文、商业软件、产业应用与验证 |

### 典型研究问题

- 哪些科研团队提出了可验证的新方法？

- 研究依赖模拟、实验还是现场数据？

- 工业软件已具有哪些类似能力？

- 某方法的真实适用范围和限制是什么？

### 专业成果与跨模块关系

> **主要成果** 数字孪生技术观察；科研团队与模型图谱；工业AI技术对标；软件与应用专题。

关联研究：与M01共享科研证据，与M03关联工程对象，由M08评价技术成熟度和潜在价值。

## M05｜政策法规、行业标准与市场准入

持续研究与材料、设备、气体质量、能源及环保应用有关的政策和标准。

| 研究方向 | 具体内容 |
|---|---|
| 材料与制造 | 先进材料、工业设备和相关产业政策 |
| 能源与低碳 | 生物天然气、CCUS、氢能、工业节能及相关政策 |
| 产品标准 | 膜材料、组件及测试方法的标准 |
| 工程规范 | 工业气体、压力系统、安全及其他适用要求 |
| 国际市场 | 重点区域法规、产品准入及认证要求 |
| 产业支持 | 研究支持、示范、产业化和技术推广政策 |

### 典型研究问题

- 政策是强制要求、推荐标准还是发展规划？

- 哪些要求影响特定产品和工况？

- 标准是否仍有效并适用于目标市场？

- 政策变化是否改变某类技术需求？

### 专业成果与跨模块关系

> **主要成果** 政策和标准图谱；变化监测；市场准入研究；政策影响专题。

关联研究：与M03工程规范、M06应用市场和M08策略分析联动。

## M06｜下游市场、客户需求与产业项目

从具体气体分离需求出发研究客户类型、工业应用及市场机会。

| 研究方向 | 具体内容 |
|---|---|
| 生物天然气 | CO₂/CH₄分离、沼气升级、燃气质量及相关项目 |
| 工业CO₂ | 工业气体分离、CO₂捕集和回收应用 |
| 氢气回收 | 炼化、化工、副产气等相关分离市场 |
| 天然气与其他气体 | 天然气处理、氮气、氦气等适用市场 |
| 客户生态 | 工业气体企业、设备商、EPC、系统商与运营商 |
| 项目与竞争 | 公开装置、商业项目、替代技术及区域差异 |

### 典型研究问题

- 谁购买膜组件、谁集成系统、谁负责运营？

- 客户实际要求什么纯度、处理量和维护水平？

- 哪些项目具有可信的实际技术需求？

- 在某应用中膜技术面临哪些替代方案？

### 专业成果与跨模块关系

> **主要成果** 应用市场图谱；产业项目情报；客户和合作生态；市场专题。

关联研究：与M02产品竞争、M03工程要求、M05政策及M08经济性联动。

## M07｜专利、供应链与产业合作生态

研究关键技术的知识产权布局、制造供应和产业合作网络。

| 研究方向 | 具体内容 |
|---|---|
| 公开专利 | 材料、制膜、组件、分离工艺、系统和软件相关专利 |
| 专利布局 | 申请人、专利族、技术分类、地域及法律状态 |
| 关键材料 | 高分子、添加剂及相关制造材料 |
| 制造设备 | 制膜、组件、工艺与相关关键装备 |
| 企业供应链 | 供应商、组件合作、系统集成与制造生态 |
| 科研合作 | 高校成果转化、许可、联合研发及产业关系 |

### 典型研究问题

- 某项新技术是否关联公开专利？

- 核心企业围绕哪些工艺进行布局？

- 哪些关键供应和制造技术值得关注？

### 专业成果与跨模块关系

> **主要成果** 专利技术图谱；供应链图谱；科研与产业合作网络；技术布局研究。

关联研究：与M01科研成果、M02商业产品和M03制造工艺关联。一般专利情报不替代法律意见。

综合前七个模块，针对具体技术、产品和市场问题提供专业研究和决策支持。

# 04｜全球竞争企业与产业竞争格局

## 4.1 竞争者应按真实竞争关系分类

| 竞争类型 | 研究对象 | 主要判断维度 |
|---|---|---|
| 直接膜材料/组件 | 同一气体、相近工况及应用的商业膜供应商 | 分离性能、可靠性、材料与组件能力 |
| 系统和工程方案 | 成套设备、工艺设计和集成企业 | 系统能耗、工程经验、服务和交付能力 |
| 替代技术 | PSA、吸收、低温和组合工艺供应商 | 在特定应用下的成本、性能和条件 |
| 新兴技术与研究 | 大学、科研机构、初创和成果转化企业 | 新技术成熟度、性能验证与产业化 |

同一企业可能横跨多个类别。特别是工业气体大型企业，其角色可能同时涉及膜供应、工程集成和终端应用，需针对具体气体、工况和采购对象确认其与某膜技术企业的直接或间接竞争程度。

# 05｜竞品与技术性能对标体系

## 5.1 三个必须分开的对标层级

| 层级 | 主要指标 | 不应混同的问题 |
|---|---|---|
| 材料层面 | 渗透系数、渗透率、理想/混合气选择性、膜厚、稳定性 | 材料指标不等于商业组件分离能力 |
| 组件层面 | 结构、有效膜面积、通量、工作压力、压降、组件寿命 | 组件测试不等于完整工艺结果 |
| 系统层面 | 原料气组成、产品纯度、回收率、能耗、处理量、成本 | 不同流程与边界不能直接排名 |

## 5.2 竞品性能评价矩阵

| 维度 | 重点指标 | 比较时必须记录 |
|---|---|---|
| 分离表现 | 渗透性、选择性、产品纯度、目标气回收率 | 气体组成、测试对象、工况和流程 |
| 组件能力 | 组件结构、有效面积、处理量、压降 | 组件规格、温度、压力、流动方式 |
| 环境与耐久 | 塑化、老化、耐污染、寿命和稳定性 | 实验持续时间及实际工程证据 |
| 能耗 | 压缩、真空、再生和辅助能源 | 完整系统边界与产品要求 |
| 成本 | 材料、组件、设备、运行维护 | CAPEX/OPEX、规模、假设与计价范围 |
| 工程服务 | 选型、工艺模拟、现场支持与维护 | 供应商实际交付范围 |
| 成熟度 | 科研、组件测试、中试、商业部署 | 试验或运行证据及其限制 |

## 5.3 数据可比性管理

| 类别 | 含义 | 处理方式 |
|---|---|---|
| 直接可比 | 对象、测试方法、工况和边界足够接近 | 支持定量横向比较 |
| 条件化比较 | 存在差异，但有合理的归一化或模型方法 | 说明条件与假设后比较 |
| 参考性资料 | 性能层级或系统边界明显不同 | 分开呈现，不直接排名 |
| 数据不足 | 缺失关键参数、来源或有效性证据 | 明确缺口，保留判断限制 |

> **典型误区** 某企业宣称其特定工艺可实现较高甲烷回收率，并不能直接证明其膜材料优于另一家企业。回收率可能受回流、级数、压缩、气源、系统边界等多因素共同影响。

## 5.4 CO₂/CH₄分离专题的关键数据

- CO₂渗透性、CO₂/CH₄选择性及混合气测试条件。

- 膜层厚度、组件形式、有效面积和处理量。

- 进气中CO₂/CH₄及其他杂质浓度，温度和压力。

- 产品气纯度、甲烷回收率及甲烷损失。

- 系统级数、回流、压缩与预处理设计。

- 单位处理量能耗、维护、可靠性及工程案例。

- 公开性能属于实测、模拟、厂家声明还是第三方验证。

## 5.5 四维综合竞品判断

| 技术 | 工程 | 商业 | 竞争 |
|---|---|---|---|
| 材料和组件性能 | 系统工况和实际适用性 | 客户、服务和可获得性 | 特定市场与替代技术关系 |

完整的竞品研究应同时说明：产品在什么条件下具有某种表现；该表现来自何种证据；它对特定客户和应用意味着什么；哪些问题尚不能从公开信息判断。

# 06｜替代技术与系统竞争分析

## 6.1 从“膜对膜”扩展到“工艺对工艺”

工业项目往往不是简单选择某一家膜组件，而是在膜分离、吸附、吸收、低温或组合技术之间进行工程选择。对膜技术竞争力的研究应纳入不同工艺路线，结合具体气体、规模和客户要求判断。

| 技术路线 | 工艺特点 | 需要研究的因素 |
|---|---|---|
| 膜分离 | 不同组分透过膜的速率存在差异 | 压力、膜面积、流程、纯度、回收率、能耗 |
| PSA/VPSA | 吸附材料与周期性变压再生 | 吸附剂、循环、产品气、再生及维护 |
| 水洗/物理吸收 | 气体在液相中物理溶解 | 用水/溶剂、压力、再生及设备 |
| 化学吸收 | 溶剂反应吸收及再生 | 溶剂、再生热耗、纯度和工艺复杂性 |
| 低温分离 | 冷却、相变与低温处理 | 规模、能耗、设备要求及副产品 |
| 混合工艺 | 不同分离机制组合 | 工艺集成、能耗与系统经济性 |

## 6.2 评价条件

| 评价因素 | 研究说明 |
|---|---|
| 原料气与杂质 | 组分、浓度、污染物及波动范围 |
| 项目规模 | 处理流量、运行小时数和负荷变化 |
| 产品要求 | 纯度、回收率、产品规格及排放要求 |
| 能源条件 | 电价、热源、压缩条件、可用能源 |
| 成本条件 | 设备投资、耗材、维护和场地 |
| 可靠性 | 运维能力、停机风险、长期稳定性 |
| 组合可能 | 膜与其他工艺组合后是否具有工程优势 |

## 6.3 应用专题示例

- 生物天然气：膜、PSA、水洗和化学吸收在给定气源、规模与天然气品质要求下的比较。

- 工业CO₂：膜、吸收与低温等技术在不同CO₂分压和捕集目的下的适用性。

- 氢气回收：膜分离与吸附等技术对纯度、回收率和能源条件的不同要求。

- 混合工艺：膜与吸收或吸附组合是否改善某项系统级指标及其代价。

# 07｜全球科研创新与数字孪生专题

## 7.1 科研生态需要建立对象关联

| 研究对象 | 主要字段 | 研究价值 |
|---|---|---|
| 科研团队 | 机构、研究方向、人员、代表成果和合作 | 长期技术创新与合作认知 |
| 新研究成果 | 模型/材料、实验设计、关键结果及限制 | 具体技术变化和可信度判断 |
| 专利及转化 | 专利族、企业、许可或成果转化信息 | 科研与产业之间的联系 |
| 技术成熟度 | 理论、材料实验、组件验证、中试、工业应用 | 判断实际应用证据 |

| 阶段 | 常见证据 | 需要警惕的问题 |
|---|---|---|
| 理论/模拟 | 理论模型、计算或仿真 | 是否存在独立实验验证 |
| 材料实验 | 小样材料和测试数据 | 膜厚、混合气与稳定性限制 |
| 组件实验 | 组件测试、工况与性能 | 制造一致性及系统边界 |
| 中试验证 | 较完整工艺或工程测试 | 扩产、可靠性与经济性 |
| 工业应用 | 公开装置、运行资料与工程结果 | 项目边界、可验证性与寿命 |

## 7.3 数字孪生技术路线

| 类型 | 核心方法 | 评估重点 |
|---|---|---|
| 机理模型 | 传质、动态系统、物理过程与守恒方程 | 物理解释性、参数和适用条件 |
| 数据驱动 | 机器学习、预测和统计模型 | 数据覆盖、外推和泛化 |
| 混合建模 | 机理与统计/机器学习结合 | 精度、校准、计算复杂度 |
| 动态数字孪生 | 模型与实际系统数据持续关联 | 更新、延迟、可靠性和验证 |
| 工业AI应用 | 诊断、优化、预测和Agent | 实际用途、约束和可靠性 |

## 7.4 软件和科研方法对标

商业软件与学术研究应放在相同技术问题下比较，但不简单认为论文提出的新算法就比成熟工业软件更先进，也不认为大型平台必然适用于高度专业化的膜分离对象。

| 研究对象 | 对标内容 |
|---|---|
| AspenTech及相关工艺模拟工具 | 过程建模、优化、混合模型及工业场景 |
| Ansys及数字孪生工具 | 多物理建模、模型部署、数据连接与验证 |
| Siemens工业工程软件生态 | 工程设计、数字孪生及与工业系统的集成 |
| MATLAB/Simulink等科研工具 | 模型开发、仿真、参数估计及科研可重复性 |
| 膜分离专项研究代码与工具 | 专业传质模型、组件与流程计算的针对性 |

## 7.5 Digital Twin Technology Watch 档案结构

| 字段 | 具体内容 |
|---|---|
| 团队与对象 | 科研机构、负责人、研究技术和设备对象 |
| 模型与方法 | 机理、数据、混合建模、算法架构 |
| 数据与验证 | 模拟、实验、现场数据，独立验证与误差 |
| 实际创新 | 相对现有方法改进了什么问题 |
| 工业适用性 | 工况限制、模型维护及数据需求 |

例如，某膜技术企业关注某高校关于数字孪生的新论文，智库可以进一步形成团队—论文—模型方法—验证数据—工业软件—应用成熟度的关联研究，避免每次从头整理单篇文献。

## 8.2 下游市场研究要素

| 要素 | 核心问题 |
|---|---|
| 需求来源 | 为什么该应用需要气体分离？ |
| 购买者与运营者 | 谁采购组件，谁集成系统，谁实际使用？ |
| 技术要求 | 产品纯度、回收率、处理规模和稳定性要求是什么？ |
| 替代方案 | 不同工艺以及竞争企业有哪些？ |
| 项目环境 | 政策、能源价格、场地、维护和采购方式如何影响选择？ |
| 市场证据 | 有哪些可核查的公开商业项目与工程资料？ |

研究应区分政策发布、示范项目、实际设备采购以及可商业化市场需求。公开项目数量不能直接当作某膜技术企业可获得的订单数量。对于具体市场规模和技术经济性结论，应明确数据来源、统计口径和假设。

## 9.3 示例一：国际企业发布新CO₂分离膜组件

| 触发信息 | 交叉研究 | 综合成果 |
|---|---|---|
| 新产品发布、技术参数、目标市场 | 产品+工程+科研+专利+市场+经济性 | 竞品档案更新、性能对标和竞争影响研究 |

研究依次核查新产品是什么、技术指标来自什么条件、与现有产品是否可比、针对哪些气体和工程工况、使用何种流程、可能涉及哪些专利、公开市场中是否有应用证据，最后形成条件清晰的竞争分析。

## 9.4 示例二：某大学团队发布新型数字孪生成果

| 科研对象 | 技术验证 | 关联价值 |
|---|---|---|
| 团队、论文、研究对象、模型方法 | 模拟/实验/真实数据、误差与限制 | 与工业模型和实际工程问题的联系 |

通过持续追踪，单篇研究可成为完整的科研团队档案及技术路线图：后续论文、专利、软件与工业合作均能关联到同一知识主题。

## 9.5 示例三：某地区发布新CO₂或生物天然气政策

| 政策事实 | 产业分析 | 专业判断 |
|---|---|---|
| 实施日期、范围、强制性和具体条款 | 相关企业、项目、工艺及产品要求 | 对目标市场和技术需求的潜在影响 |

应避免直接把鼓励性政策等同于实际订单；对于经济性和市场影响需结合工程技术和项目条件再判断。

## 9.6 示例四：评估一个具体气体分离应用

研究可同时整合材料与组件数据、工艺路线、客户目标、能源价格、标准要求以及替代技术，形成“在何种条件下某类膜技术值得选择”的综合评价，而不是简单给出跨场景的绝对技术排名。

# 11｜质量管理与可信研究体系

## 11.1 五类证据与研究结果

| 证据类别 | 内容示例 | 呈现要求 |
|---|---|---|
| 官方或经核实事实 | 正式标准、政策、产品文件、公开登记 | 核查来源、日期与版本 |
| 企业公开声明 | 厂家性能、寿命、案例和商业说明 | 明确属于企业声明，勿自动视为独立验证 |
| 学术研究结果 | 论文、实验、模拟与模型 | 记录实验条件、方法和局限 |
| 第三方行业分析 | 研究机构、专业报告、产业统计 | 核查统计口径、方法和适用性 |
| 专业判断与假设 | 技术趋势、经济性和竞争影响推断 | 标注证据、关键条件及不确定性 |

## 11.2 六项质量原则

**真实性**：重要信息具有可核实来源，不通过二次转载取代原始出处。

**专业性**：理解材料、组件、工艺和数字模型的技术区别。

**可比性**：同层级及相近边界下比较指标，对不适配数据单独标注。

**连续性**：重要研究主题持续维护，而不是重复生成孤立的文件。

**适用性**：技术和商业判断必须对应明确气体、工况、客户或市场。

**客观性**：区分事实、声明、科研结果、模型推断和专业建议。

## 11.3 研究成果应保留的元数据

| 基础信息 | 要求 |
|---|---|
| 时间与出处 | 发布日期、查阅日期、原始链接或正式文献引用 |
| 研究对象 | 企业、产品、科研团队、工艺或具体技术 |
| 条件与单位 | 温度、压力、组分、测试方法、系统边界和单位 |
| 信息等级 | 来源可信度、是否企业声明、是否经过独立验证 |
| 研究逻辑 | 分析方法、假设、数据缺失和局限性 |
| 主题关联 | 相关的产品、技术、市场、标准和研究结论 |

## 12.2 方案的三个核心特征

> **专业技术深度** 不仅关注行业新闻和产品介绍，还分析技术路线、数据条件、工程适用性、成熟度和实际证据。

> **跨模块知识关联** 连接科研、材料、产品、工艺、数字孪生、政策、市场及商业工程，形成针对实际问题的完整研究链。

> **持续使用的知识资产** 通过企业与产品档案、专业数据、知识图谱及历史研究结论，使研究能够更新、检索、比较与复用。

本方案以某膜技术企业的气体分离膜及相关工程技术为专业基础，以全球科研、竞争产品、数字孪生与工业应用研究为重要方向，延伸至政策、市场、专利、供应链和技术经济性。通过八大研究模块与六类服务产品，提供持续可靠的外部技术和产业研究支持，使研发、产品、工程和商业判断能够建立在更系统和可核查的证据之上。
