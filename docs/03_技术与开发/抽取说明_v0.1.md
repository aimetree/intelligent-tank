## 2. 抽什么

1. **只抽这份来源自己得到的数**：自己测的、自己算的。引自别的文献的数不抽，包括引言里的数、文献对比表里带参考文献号的行。在输出的 `notes` 里写一句：哪张表、哪几行是转引的。
2. **指标**　字典里的指标。`entry` 是 `derived` 或 `relations` 的不抽。
   - 核心指标（`grade` 是 `core`）：逐项找，结果写进 `core_check`（第 9 节）。
   - 扩展指标（`grade` 是 `extended`）：正文或表里有数的抽；只有图的不读图。
3. **对象**　任务单样品清单里的样品。
   - 清单上“读图”一栏是“是”的样品：核心指标只有图里有的，要读图（第 8 节）。“否”的只抽正文和表里的数。
   - 清单之外的膜，原文给了它自己测的数的：照样抽，`sample_label` 照原文写，不写 `subject_id`，并在 `notes` 里说明。
4. **粒度**　一条证据是一个样品、一个指标、一组条件、原文里的一处。同一个指标在不同电流密度、不同测试溶液、不同圈数下的值，各是一条。
5. **同一个数在原文里出现几次的，只记一条**，取下面顺序里最先有的一处：① 表；② 结果与讨论部分的正文，按页码最靠前的一处；③ 实验部分；④ 摘要、结论。前四处都没有才读图。
6. **原文自己对不上的**（同一个量两处写的数不一样）：两处各记一条，各自的 `internal_note` 写明和哪一处不一致，并在 `notes` 里说明。不判断哪个对。
7. **不补**　原文没有写的条件写 `not_reported`，不从别的论文、常识或作者以前的工作里补（方案 5.4）。

## 3. 一条证据怎么写

输出里的每条证据是一个 JSON 对象。编号、状态、录入人这些登记时才有的字段不用写。

| 字段 | 怎么写 |
|---|---|
| `sample_label` | 样品清单里的 `label`，一个字不差。原文在别处用了别的叫法（清单“别名”一栏）也写清单里的 `label` |
| `subject_id` | 样品清单里这个样品的 `subject_id` |
| `indicator` | 字典里指标的键 |
| `level` | 字典里这项指标的 `level` |
| `content_kind` | 字典里这项指标的 `value_kind`：`numeric`、`category`、`statement` |
| `value_reported` | 数值型必填。字符串，照原文的数字抄，保留原文的位数，不带单位。科学记数写成 `1.99×10^-9`、`458×10^4`（乘号用 ×，指数前加 ^）。表头或坐标轴带倍率的（如表头写 10⁻⁹ cm² min⁻¹，格子里是 1.99），把倍率并进来写成 `1.99×10^-9`，`internal_note` 写“倍率在表头” |
| `unit_reported` | 数值型必填。写字典里这项指标 `units_accepted` 中和原文单位相同的那个代码（原文 mS cm⁻¹ 写 `mS/cm`，mΩ cm² 写 `mohm*cm2`，µm 写 `um`）。不换算：原文是 S/cm 就写 `S/cm`。原文的单位不在 `units_accepted` 里的，照同样的写法写原文单位，并在 `notes` 里说明 |
| `value_qualifier` | 原文是确切的数不用写。“约、≈、about”写 `approx`；“高于、above、>”写 `gt`；“不低于、≥”写 `ge`；“低于、<”写 `lt`；“不高于、≤”写 `le` |
| 只有范围的 | 原文对一个样品只给了范围（如 9 to 12）、没有给确切的数的，这一版先不抽，在 `notes` 里记下原文的写法和位置。`range_low`、`range_high` 不用 |
| `uncertainty`、`uncertainty_kind` | 原文写了“± 多少”的填。类别只在原文写明时写 `sd`、`se`、`ci95`、`range`；没写明是哪一种的写 `not_stated` |
| `n` | 原文写了重复测了几次或几个样的才填 |
| `category_value` | 分类型必填，取值在字典这项指标的 `allowed_values` 里 |
| `summary` | 陈述型必填。用我们自己的话写一两句中文，只写原文说了什么，数值连单位写进去，不评价 |
| `conditions` | 见第 4 节 |
| `conditions_locator`、`conditions_snippet` | 条件写在原文别的地方（多半是实验部分）时填：位置照第 6 节，片段照第 5 节抄写了这些条件的那一段 |
| `evidence_type` | 自己测的写 `experimental`；模拟、模型算出来的写 `model_simulation`。由自己测的数加一个假定算出来的（如按假定的 10 µm 厚度算的面电阻）写 `experimental`，并在 `scope_note` 里用中文写明这个假定 |
| `obtained_from` | `text` 正文；`table` 表；`figure_read` 图上读数 |
| `locator` | 见第 6 节 |
| `snippet` | 见第 5 节。图上读数不写 |
| `figure_read` | 图上读数必填，见第 8 节 |
| `scope_note` | 可选。这个数的适用范围和限制，中文，可对外 |
| `internal_note` | 可选。给核对的人看的话，中文 |

`series_label`、`baseline_ref`、`control_ref` 不用写，登记时由 Claude 统一加。`fact`、`questions` 是非学术来源用的，论文不写。

## 4. 条件

- 字典里这项指标 `required_conditions` 的每一个键都要出现在 `conditions` 里。器件层的指标是那七项加指标自己多要的。
- `optional_conditions` 里的键：数值型、分类型的，原文写了就记；文字型的（`value_kind` 是 `text`）这一版先不记。
- 原文没写的写 `"not_reported"`。这个条件对这条数据说不通的写 `"not_applicable"`。
- 写了的条件是一个对象，`reported` 必填，照抄原文里写这个条件的最短的一段（连数带单位，如 `80 mA cm-2`、`1.5 M VO2+ in 3 M SA`）。其余按条件的 `value_kind`：

| `value_kind` | 再写什么 | 例 |
|---|---|---|
| `numeric` | `value` 是数，`unit` 是字典里这个条件的 `unit_std`。只做写法上的转换：M 就是 mol/L，ml 就是 mL，mA cm⁻² 就是 mA/cm2。要做算术才能得到的（如由电流和面积算电流密度）不算，只写 `reported`。“室温”“RT”只写 `reported`，不换成数字 | `{"reported": "80 mA cm-2", "value": 80, "unit": "mA/cm2"}` |
| `numeric_range` | `low`、`high` 两个数，`unit` 同上 | `{"reported": "1.6 V and 0.7 V", "low": 0.7, "high": 1.6, "unit": "V"}` |
| `category` | `value` 是字典里 `allowed_values` 中的一个 | `{"reported": "through-plane", "value": "through_plane"}` |
| `text`，说的是溶液的：`acid`、`test_solution`、`donor_solution`、`receiver_solution` | `value` 写成规范的一句：每个组分是“化学式 浓度 mol/L”，几个组分用“ + ”连起来，钒盐或别的盐在前，酸在后。原文没给浓度的组分只写化学式 | `{"reported": "1.5 M VOSO4 (CV) in 2 M SA", "value": "VOSO4 1.5 mol/L + H2SO4 2 mol/L"}` |
| `text`，其余的：`method`、`cycle_index`、`selectivity_definition`、`stability_method`、`price_basis` 等 | 只写 `reported`，不写 `value` | `{"reported": "average of five cycles"}` |

- `vanadium_conc` 是电解液的总钒浓度。两侧写法不同但浓度相同的（如正极 1.5 M VO²⁺、负极 1.5 M V³⁺）记 1.5；两侧浓度不同的只写 `reported`，并在 `internal_note` 里说明。
- `electrolyte_volume` 是每一侧的体积。
- `cycle_index`：照原文写这是第几圈的值，或者几圈的平均（如 `500th cycle`、`average of five cycles`）。

## 5. 原文片段

- 从来源文本里**逐字**抄，一个字不改，不省略中间的字，不把两处拼在一起。空格和换行多一个少一个没关系。
- 抄最短的、又能看出“是哪个样品、哪个数”的一段：正文抄数值所在的那一句（句子很长时抄含样品名和数值的那一截）；表抄那一行，从〔按版面〕的排法里抄，只抄表格自己的那几格，不带同一行右边另一栏的字。
- 片段里要有 `value_reported` 里的数字（倍率在表头的除外）。不超过 300 个字符。不跨页。
- 抽出来的文本里上标、下标都变成了普通的字，负号后面常多一个空格（如 `mS cm− 1`、`458x104`）：照文本里的样子抄，不要改回去。
- 片段只留内部，不对外（D-56）。

## 6. 出处位置

`locator` 是一个对象：

| 键 | 怎么写 |
|---|---|
| `page` | PDF 文件里的第几页（来源文本里〔第 N 页〕的 N），写成字符串。必填 |
| `table` | 在表里的写表号，只写号：`"1"`、`"S2"` |
| `figure` | 在图里的写图号和分图：`"7a"`、`"S5"` |
| `section` | 在正文里的写节号：`"3.6"`；摘要写 `"Abstract"`，结论没有节号的写 `"Conclusions"` |
| `item` | 可选。表里的哪一行，图里的哪条曲线、哪个点 |
| `text` | 必填。一句能读的中文：`第 7 页，表 1，第 1 行` |

`table`、`figure`、`section` 三个只写一个：数是从哪里取的就写哪个。

## 7. 几项指标的特别规定

字典的 `definition` 和 `notes` 先看。下面是字典没有写到的：

| 指标 | 规定 |
|---|---|
| `fluorine_class` | 样品清单里角色是 `studied` 的每个样品一条，分类型。`category_value` 照结构判断：主链、侧链、增强层、共混组分里都没有含氟聚合物的是 `non_fluorinated`；全氟磺酸是 `perfluorinated`；其余含氟的是 `partially_fluorinated`。片段抄原文里写明这张膜是什么聚合物的那一句，`internal_note` 写判断的理由。清单里系列变体很多、只是处理条件不同的，只给“读图”是“是”的样品写 |
| `thickness` | 干膜、湿膜各记各的，`thickness_state` 写 `dry` 或 `wet`。在酸里掺杂或平衡之后量的算 `wet` |
| `proton_conductivity`、`area_resistance` | 膜自己的电导率和面电阻（离线测的）。在含钒溶液里测的也记在这里，`test_solution` 照实写。按假定厚度算的面电阻见第 3 节 `evidence_type` 一行。电池的面电阻（极化曲线或电池阻抗得到的）记 `cell_area_resistance` |
| `ion_selectivity` | 只记原文自己给出的选择性数值，`selectivity_definition` 抄原文的定义。我们不用电导率除以渗透率去算 |
| 三项效率 | 每个样品、每个电流密度各一条。正文给了数的用正文的数；正文没有、图里有的，照第 8 节读图。原文写的是几圈的平均，在 `internal_note` 里写明 |
| `cycle_number` | 每个样品只记最长的那一次循环测试的圈数，条件里的电流密度写那次测试的 |
| `test_duration` | 原文写了小时数或天数才记，不由圈数推算 |
| `capacity_retention` | 原文给保持率的记保持率（单位 `%`）；给每圈衰减率的记衰减率（单位 `%/cycle`）。原文给的是容量损失了百分之多少（loss、fade、decay）的，照原文的数记，单位 `%`，并且**一定**在 `scope_note` 里写“原文给的是容量损失，不是保持率”。不互相换算 |
| `oxidative_stability` | 原文做了离线的稳定性测试（五价钒浸泡、芬顿试剂等）才记，陈述型，方法、溶液、温度、时长、结果都写进 `summary`。电池循环之后膜的变化记 `post_cycling_membrane_change` |
| `stack_validation` | 原文报告了多节电堆的测试，记 `yes`，节数、单片面积、功率、时长写进条件；原文明说没有做电堆的记 `no`；只做了单电池、没提电堆的，不出证据，`core_check` 写 `not_reported` |
| `membrane_price` | 论文里给了这张膜的价格或成本估计才记，证据类型照字典 |

## 8. 图上读数

只在第 2 节允许的情况下读：核心指标，样品清单里“读图”是“是”，正文、表、补充材料的表里都没有这个数。

1. 把那一页渲染成图片（`pdftoppm -r 300 -f N -l N -png`），裁出那张图放大看。临时文件放在任务单写的工作目录里。
2. 在图片上量出纵轴上两个刻度的像素位置和数据点中心的像素位置，线性插值出数值。对数轴按对数插值。数据点是空心或叠在一起看不清的，照能分辨的写，并在 `internal_note` 里说明。
3. 读到的数写到坐标轴最小刻度间隔的十分之一那一位。
4. `obtained_from` 写 `figure_read`；不写 `snippet`；`locator.figure` 写图号和分图，`item` 写哪条曲线、哪个点。
5. `figure_read` 写三项：`method`（一句中文：用的哪两个刻度、怎么插值的）、`read_by` 写 `claude`、`source_data_checked`（找过源数据表和补充材料、没有找到的写 `none_found`；这次没法找的写 `not_checked`，如补充材料不在手上）。
6. 误差棒先不读。
7. 一张图上一个样品的一条线上，每个数据点一条证据；横轴的值（如电流密度）写进条件。

图上读数由人复读一遍（D-34），两遍 AI 读数之差只并排列出，不算不一致。

## 9. 输出

写成一个 JSON 文件，路径是任务单里给的：

```json
{
  "source_id": "SRC-000001",
  "pass": 1,
  "evidence": [ { "…": "一条证据" } ],
  "core_check": { "thickness": "found", "membrane_price": "not_reported" },
  "notes": [ "表 1 第 3 到 6 行是转引的，没有抽" ]
}
```

- `core_check`：字典里 `grade` 是 `core`、`entry` 不是 `derived` 和 `relations` 的每一项指标一个键。这份来源（连同它的补充材料）里抽到了这项指标的证据写 `found`；从头到尾找过、原文没有的写 `not_reported`；这项指标对这类对象说不通的写 `not_applicable`。拿不准用哪个时写 `not_reported`。
- `notes`：转引的表；清单之外的样品；原文自己对不上的地方；单位不在字典里的；你拿不准、想让核对的人留意的地方。每条一句中文。

## 10. 交之前自己查一遍

1. 文件是合法的 JSON。
2. 每条的 `indicator` 在字典里，`level`、`content_kind` 和字典一致；数值型有 `value_reported` 和 `unit_reported`。
3. 必填条件一个不少。
4. 不是图上读数的每一条都有 `snippet`，并且在来源文本里逐字找得到。可以用仓库里的函数查：

```bash
python3 - <<'EOF'
import json, sys
sys.path.insert(0, "tools")
import textmatch as T
text = open("来源文本的路径", encoding="utf-8").read()
for i, e in enumerate(json.load(open("你的输出文件", encoding="utf-8"))["evidence"]):
    for key in ("snippet", "conditions_snippet"):
        if e.get(key):
            ok, why = T.find_snippet(e[key], text)
            if not ok:
                print(i, e.get("sample_label"), e.get("indicator"), key, why)
EOF
```

5. `sample_label` 都在样品清单里，或者在 `notes` 里说明过。
6. `core_check` 写了 `found` 的都有证据，有证据的都写了 `found`。

查出来的问题改掉再交。改不掉的（如片段确实找不到）留着，在 `notes` 里说明。

## 11. 不做的

- 不补原文没有的条件，不换算单位，不算原文没给的数（比值、平均、保持率）。
- 不评价，不写“更好”“优于”这类词（D-60）。
- 不复制原图，不大段抄原文：片段只抄一句或表格的一行（D-56）。
- 不看另一遍的结果，不看以前的预检记录。
