# 项目总览与决策
## 1. 当前项目定义
产业科技智库与专业情报业务A：把科研、技术、产品、竞争、政策、市场、工程应用及产业资源组织成有来源、可更新的专业知识、数据与研究判断。
品牌文件采用Industry Intelligence / 项目团队；通用方案封面为Industry Intelligence INTELLIGENCE。独立的智库产品品牌与最终命名尚未正式确定。
这是一个规划中的产品与服务体系，不能据此宣称已有完整平台、数据库规模、付费订阅或经验证的壁垒。

## 2. 已明确的用户要求
| 要求 | 接手时如何执行 |
|---|---|
| 业务A须独立展开 | 不用公司总体三大业务框架取代A的完整产品逻辑 |
| 跨行业、跨客户迁移 | 某膜技术企业只作膜与气体分离行业包示例，不能把平台做成单一客户方案 |
| 模块化、具体成果 | 用表格、矩阵和结构组织研究能力、产品与客户价值 |
| 某膜技术企业方案不含实施计划 | 不主动加入时间线、团队预算、执行排期或公司战略框架 |
| 某研究人员以科研为主 | 不照搬企业战略/创业导向；不预设他希望创业 |
| 科研导向仍包括产业 | 保留专利、初创公司、成熟企业、商业产品、工程应用和合作研究 |
| 不讲对方已熟悉的背景 | 对外学术版直接介绍服务、研究问题、交付 |
| 最新学术版M07是情报 | 总结已有计算、模拟、AI与数字技术的研究进展，不提供具体计算、模型或算法开发 |
| 不替客户猜选择 | 展示可能性、适用条件及待确认问题，避免单一路线的武断推荐 |
| 交付完整文件 | 不仅提供大纲或声称已经生成文件 |

## 3. 三类方案的关系
### 通用业务A
权威文件：产业科技智库_业务A_跨行业可迁移产品体系_完整方案.docx。
定位是共享底座、标准产品、行业知识包、客户场景，支持企业、咨询、政府园区、科研、投资技术团队、软件数据伙伴。
### 某膜技术企业企业版
权威文件：某膜技术企业_产业科技智库与战略情报服务方案_完整版.docx。
面向气体分离膜材料—制造组件—工艺装备—数字工程—工业应用—产业生态，支持研发、产品、工程及商业判断。
A提供研究情报；某膜技术企业的B数字孪生工作和C智能运营布局不默认纳入A交付。
### 某研究人员学术版
优先采用最新文件：膜科学与先进电化学技术_智库服务方案_完整修订版.docx。
某研究机构 某膜领域研究人员是拟交流对象，不等同已签约客户。方向覆盖功能性微孔聚合物、选择性离子传输、电化学储能膜、离子资源分离、电化学能源、制造组件、计算研究。
两个“膜技术创新与产业转化…学术合作交流版”是保留的早期方案，不应覆盖最新明确要求。

## 4. 研究边界
- 提供科技和产业情报，不自动承诺实验、工程实施、现场控制或具体算法开发。
- 专利技术研究不等于正式法律意见或FTO结论。
- 不以科研材料、商业组件、完整工艺系统的不同层级指标直接互相比优劣。
- 客户资料须授权并隔离；公共来源不意味着具有商业再分发权。
- 早期建议的试点、流程建设、数据库均属候选机会，尚未成为用户确认的最终业务路线。
